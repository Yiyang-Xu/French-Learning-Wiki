## s'appeler

### Méthode de conjugaison

`17:27`

| Personne | Conjugaison |
| --- | --- |
| je | m'appelle |
| tu | t'appelles |
| il / elle | s'appelle |
| nous | nous appelons |
| vous | vous appelez |
| ils / elles | s'appellent |

> [!note]
> *nous nous appelons*：第一个 *nous* 是主语人称代词；第二个 *nous* 是 *se* 对应 *nous* 的自反代词。

**变位提示：**省音
