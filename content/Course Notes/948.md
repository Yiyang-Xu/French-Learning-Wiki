## se 与代词式动词

*s'appeler* 是一个代词式动词。词典中写作 *se + 动词*，实际使用时，*se* 会随主语变化。

| Sujet | Pronom réfléchi |
| --- | --- |
| je | me |
| tu | te |
| il / elle | se |
| nous | nous |
| vous | vous |
| ils / elles | se |

> [!note] À retenir
> 主语和自反代词要配套记：*je me, tu te, il/elle se, nous nous, vous vous, ils/elles se*。

---

## appeler

**appeler**：叫、呼叫；给某人打电话等。

| Personne | Conjugaison |
| --- | --- |
| j' | **appelle** |
| tu | **appelles** |
| il / elle | **appelle** |
| nous | appelons |
| vous | appelez |
| ils / elles | **appellent** |

> [!tip] 变位提示
> *je / tu / il / elle / ils / elles* 中词干写作 **appell-**；*nous / vous* 保持 **appel-**。

**例句**
- *J'appelle Paul.* — 我给 Paul 打电话 / 我叫 Paul。
- *Nous appelons le professeur.* — 我们叫老师。

---

## s'appeler

**s'appeler** 表示“叫……名字 / 名叫……”，是介绍姓名时最常用的动词之一。

结构可以理解为：

**主语 + 对应的自反代词 + appeler 的变位**

| Personne | Conjugaison |
| --- | --- |
| je | m'appelle |
| tu | t'appelles |
| il / elle | s'appelle |
| nous | nous appelons |
| vous | vous appelez |
| ils / elles | s'appellent |

> [!note] 省音
> *me / te / se* 后面遇到元音开头的 *appeler* 时变成 *m' / t' / s'*：*je m'appelle, tu t'appelles, il s'appelle*。

> [!note]
> *nous nous appelons* 中，第一个 *nous* 是主语，第二个 *nous* 是自反代词。

---

## Se présenter / présenter quelqu'un

**介绍自己**
- *Je m'appelle Alice.* — 我叫 Alice。
- *Moi, je m'appelle Paul.* — 我呢，我叫 Paul。

**询问姓名**
- *Comment vous vous appelez ?* — 您叫什么名字？
- *Tu t'appelles comment ?* — 你叫什么名字？（口语）

**介绍别人**
- *Il s'appelle Yves.* — 他叫 Yves。
- *Elle s'appelle Nicole.* — 她叫 Nicole。

> [!tip] 本课记忆重点
> 不要只背 *s'appeler = 叫做*。真正需要掌握的是“主语 + 自反代词 + 动词变位”这一整套结构。
